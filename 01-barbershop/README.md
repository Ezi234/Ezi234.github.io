# БРИТВА №9 — лендинг барбершопа

Готовый одностраничный сайт: тёмный премиум-дизайн, настоящие фотографии, онлайн-запись,
портфолио с фильтром и лайтбоксом, слайдер отзывов, карта. Чистые HTML, CSS и JavaScript —
без фреймворков, сборки и внешних библиотек.

---

## Что внутри

```
01-barbershop/
├── index.html      разметка страницы
├── css/style.css   все стили
├── js/main.js      вся интерактивность
├── img/            фотографии (WebP), обложка для соцсетей, favicon
├── login/          экран входа в кабинет с двухфакторной защитой
└── README.md       этот файл
```

Ни npm, ни сборщика, ни базы данных.

---

## Как запустить

Из папки `WebSites` (на уровень выше):

```bash
node dev-server.js
```

Откройте `http://localhost:5173/01-barbershop/`.

Открывать `index.html` двойным щелчком не стоит: в протоколе `file://` браузер
блокирует загрузку CSS и JS из-за политики безопасности, и страница будет пустой.

---

## Работает ли без VPN

Сам сайт — да: все фотографии, стили и скрипты лежат в его папке, страница не обращается
ни к одному зарубежному серверу. Единственный сторонний адрес — карта Яндекса, и она
загружается, только когда посетитель нажмёт «Показать карту».

Без VPN не откроется только в одном случае — если залить сайт на хостинг, который
в России замедляют (Cloudflare Pages, Netlify и т. п.). Куда заливать, чтобы всё
открывалось, — в файле `ЗАЛИВКА.md` в корне папки `WebSites`, раздел про Россию.

## Подключение формы к серверу

Сейчас формы работают в демо-режиме: данные проверяются, собираются и выводятся в консоль
браузера. Чтобы заявки приходили по-настоящему, откройте `js/main.js`, найдите блок с
пометкой `ЗДЕСЬ ПОДКЛЮЧАЕТСЯ ОТПРАВКА НА СЕРВЕР` и замените заглушку:

```js
fetch('/api/booking', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data)
});
```

Куда отправлять — на выбор:

- **свой обработчик** на PHP, Node.js или Python;
- **Telegram-бот** — заявка падает в чат владельца;
- **CRM** барбершопа, если у неё есть открытый API.

> Проверку данных обязательно продублируйте на сервере. Валидация в браузере спасает от
> опечаток клиента, но не от злоумышленника: он просто отправит запрос мимо страницы.

## Безопасность

Что уже сделано в коде:

- **Content-Security-Policy** — страница грузит только собственные файлы. Исключение одно:
  фрейм карты с `yandex.ru` (`frame-src`), и он создаётся только по нажатию кнопки.
- **Никаких `onclick` в разметке** — все обработчики вешаются из `main.js`. Именно это
  позволяет держать строгий CSP без послабления `unsafe-inline`.
- **Защита от XSS** — данные пользователя попадают на страницу только через `textContent`.
  Введённое в поле имя не может стать исполняемым кодом.
- **Ловушка для ботов** (honeypot) — скрытое поле, которое человек не видит, а спам-скрипт
  заполняет. Такие заявки отсекаются и наружу не уходят.
- **Ограничение длины** — значения обрезаются до 500 символов, телефон приводится к цифрам.
- **Нет `eval` и `new Function`** — исполняемого кода из строк в проекте нет.

Заголовки, которые нельзя задать из HTML, уже прописаны в корне `WebSites`:
`_headers` (для Cloudflare и Netlify) и `.htaccess` (для обычного российского хостинга
на Apache — Beget, Timeweb, Reg.ru). И обязательно HTTPS.

## Как переделать под другого клиента

**Цвета.** Все оттенки собраны в начале `css/style.css` в блоке `:root`. Смена `--gold`
на другой цвет перекрашивает весь сайт: кнопки, акценты, иконки, подчёркивания.

**Шрифты.** Используются системные (`--font-head` и `--font-body`), поэтому сайт грузится
мгновенно и не зависит от Google Fonts, которые в России работают нестабильно.

**Фотографии.** Положите свой файл с тем же именем в `img/` — вёрстка сама обрежет его
по нужной пропорции. Пропорции и размеры — в `КАК-ЗАМЕНИТЬ-КАРТИНКИ.md` в корне `WebSites`.
Портреты мастеров на сайте показываются в ч/б, поэтому цвет фона на них не важен.

**Карта.** Координаты точки — в атрибуте `data-map-src` у блока `#map` в `index.html`
(`ll` — центр карты, `pt` — метка, формат «долгота,широта»). Там же ссылка на маршрут.

**Тексты, цены, услуги.** Всё лежит прямо в `index.html` осмысленными блоками — искать
по названию раздела в комментариях. Число работ в фильтре галереи (`filter__count`)
поправьте вручную, если добавите или уберёте фото.

## Совместимость

Chrome, Firefox, Safari, Edge и мобильные браузеры актуальных версий (фото в WebP).
В браузерах без `IntersectionObserver` анимации появления просто отключаются —
содержимое показывается сразу, ничего не ломается.

Учтена системная настройка «уменьшить движение»: при её включении анимации отключаются.
Есть стили для печати — страница нормально выводится на бумагу.
