# ПОРЯДОК — лендинг ремонта квартир

Светлый «издательский» одностраничник с живым калькулятором сметы, перетаскиваемым
сравнением «до и после» и портфолио с лайтбоксом. Чистые HTML, CSS и JavaScript —
без фреймворков, сборки и внешних библиотек.

---

## Что внутри

```
02-renovation/
├── index.html      разметка страницы
├── css/style.css   все стили
├── js/main.js      вся интерактивность
├── img/            иллюстрации интерьеров, favicon, обложка для соцсетей
└── README.md       этот файл
```

Иллюстрации комнат нарисованы в SVG вручную. Они масштабируются без потери качества,
весят единицы килобайт и не требуют ни одного внешнего запроса.

---

## Как запустить

Из папки `WebSites` (на уровень выше):

```bash
node dev-server.js
```

Откройте `http://localhost:5173/02-renovation/`.

Открывать `index.html` двойным щелчком не стоит: в протоколе `file://` браузер
блокирует загрузку CSS и JS из-за политики безопасности, и страница будет пустой.

## Калькулятор: как считает и как поменять цены

Все ставки лежат в начале блока `9. Калькулятор сметы` в `js/main.js`:

```js
var RATES = { cosmetic: 4500,  capital: 9800,   design: 16500 };  // ₽ за м²
var BATH  = { cosmetic: 70000, capital: 145000, design: 210000 }; // ₽ за санузел
var PACE  = { cosmetic: 0.55,  capital: 1.05,   design: 1.45 };   // дней на м²
```

Формула:

```
цена = площадь × ставка + санузлы × цена санузла
       + доплаты за опции (₽/м², проценты, фиксированные суммы)
цена «до» = цена × 1,18
срок = площадь × темп + санузлы × 8 дней, но не меньше 14
```

Опции задаются прямо в разметке, в атрибутах `data-kind` и `data-amount`:

- `data-kind="rate"` — прибавка к цене за квадратный метр;
- `data-kind="percent"` — процент от суммы;
- `data-kind="fixed"` — фиксированная сумма.

Чтобы добавить свою опцию, достаточно скопировать `<label class="opt">` в `index.html`
и задать нужные `data-kind` и `data-amount`. JavaScript править не придётся.

Ставки в прайсе на карточках услуг (`index.html`) и в калькуляторе — это два разных
места. Меняя цены, поправьте оба, иначе клиент заметит расхождение.

## Подключение формы к серверу

Сейчас формы работают в демо-режиме: данные проверяются, собираются и выводятся в консоль
браузера. Чтобы заявки приходили по-настоящему, откройте `js/main.js`, найдите блок с
пометкой `ЗДЕСЬ ПОДКЛЮЧАЕТСЯ ОТПРАВКА НА СЕРВЕР` и замените заглушку:

```js
fetch('/api/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(data)
});
```

Куда отправлять — на выбор: свой обработчик на PHP или Node.js, Telegram-бот,
готовый сервис форм (Formspree, Getform) или CRM компании, если у неё есть API.

> Проверку данных обязательно продублируйте на сервере. Валидация в браузере спасает от
> опечаток клиента, но не от злоумышленника: он просто отправит запрос мимо страницы.

Из калькулятора в заявку автоматически подставляется расчёт — поле `estimate`
в отправляемых данных. Менеджеру сразу видно, что человек считал перед звонком.

## Безопасность

Что уже сделано в коде:

- **Content-Security-Policy** — страница грузит только собственные файлы. Внедрить чужой
  скрипт через рекламный блок или подмену CDN не выйдет, потому что внешних источников нет вовсе.
- **Никаких `onclick` в разметке** — все обработчики вешаются из `main.js`. Именно это
  позволяет держать строгий CSP без послабления `unsafe-inline`.
- **Защита от XSS** — данные пользователя и подписи в лайтбоксе выводятся через `textContent`.
  Введённое в поле имя не может стать исполняемым кодом.
- **Ловушка для ботов** (honeypot) — скрытое поле, которое человек не видит, а спам-скрипт
  заполняет. Такие заявки отсекаются и наружу не уходят.
- **Ограничение длины** — значения обрезаются до 500 символов, телефон приводится к цифрам.
- **Нет `eval` и `new Function`** — исполняемого кода из строк в проекте нет.

Что нужно донастроить на сервере (в самом HTML эти заголовки не работают):

```nginx
add_header Content-Security-Policy "frame-ancestors 'none'" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
```

И обязательно HTTPS — сертификат Let's Encrypt бесплатный и ставится за пару минут.

## Как переделать под другого клиента

**Цвета.** Вся палитра собрана в начале `css/style.css` в блоке `:root`. Смена `--clay`
на другой цвет перекрашивает акценты по всему сайту: кнопки, номера этапов, полосу
прогресса, иконки, подчёркивания.

**Шрифты.** Используются системные, поэтому сайт грузится мгновенно и работает офлайн.
При подключении внешнего шрифта не забудьте добавить его источник в CSP.

**Иллюстрации.** В папке `img/` лежат четыре сцены: `room-before`, `room-after`,
`scene-kitchen`, `scene-bath`. Их можно заменить на реальные фотографии — размеры
подобраны под соотношение 4:3, менять разметку не нужно. Для блока «до и после»
важно снимать обе фотографии с одной точки, иначе сравнение выглядит неубедительно.

**Тексты, цены, этапы, вопросы.** Всё лежит прямо в `index.html` осмысленными блоками —
искать по названию раздела в комментариях.

## Совместимость

Chrome, Firefox, Safari, Edge и мобильные браузеры актуальных версий.
В браузерах без `IntersectionObserver` анимации появления отключаются, а содержимое
показывается сразу — ничего не ломается.

Учтена системная настройка «уменьшить движение»: при её включении отключаются анимации,
бегущая строка и перекрутка цифр в калькуляторе — суммы просто подставляются.
Есть стили для печати: тёмные секции светлеют, служебные элементы скрываются.
