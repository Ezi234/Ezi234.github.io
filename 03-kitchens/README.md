# ФАСАД — лендинг кухонь на заказ с 3D-конструктором

Светлый холодный лендинг, в центре которого настоящая трёхмерная модель кухни:
её можно крутить мышью, менять фасады, столешницу и фурнитуру, а цена
пересчитывается на лету. Чистые HTML, CSS и JavaScript — без фреймворков,
сборки и внешних библиотек.

---

## Что внутри

```
03-kitchens/
├── index.html         разметка страницы
├── css/style.css      все стили
├── js/kitchen3d.js    трёхмерная сцена (собственный WebGL-рендер)
├── js/main.js         конструктор, формы, вся остальная интерактивность
├── img/               иллюстрации проектов, favicon, обложка для соцсетей
└── README.md          этот файл
```

---

## Как запустить

Из папки `WebSites` (на уровень выше):

```bash
node dev-server.js
```

Откройте `http://localhost:5173/03-kitchens/`.

Открывать `index.html` двойным щелчком не стоит: в протоколе `file://` браузер
блокирует загрузку CSS и JS из-за политики безопасности, и страница будет пустой.

## Трёхмерная сцена: как она устроена

Никаких three.js и загрузчиков моделей. `js/kitchen3d.js` — это примерно
четыреста строк, которые делают всё сами:

- **Геометрия строится кодом.** Кухня собрана из параллелепипедов: шкафы, столешница,
  остров, вытяжка, барные стулья, светильники. Функция `Builder.box()` добавляет
  куб с координатами, размерами и цветом; сцена — это просто список вызовов.
- **Освещение считается в шейдере.** Основной свет, подсветка с обратной стороны,
  мягкий свет сверху и блик. Плюс лёгкая дымка вдаль, чтобы объём читался.
- **Матричная математика своя** — перспектива и `lookAt` занимают тридцать строк.
- **Управление**: перетаскивание мышью и пальцем, стрелки на клавиатуре,
  медленный автоповорот, когда посетитель ничего не трогает.

Почему так, а не библиотека: страница остаётся полностью автономной и держит
строгий Content-Security-Policy, а весь рендер весит несколько килобайт
вместо шестисот у минифицированного three.js.

### Бережное отношение к слабым машинам

- Плотность пикселей ограничена коэффициентом 1,75 — на экранах Retina сцена
  не рисуется в четыре раза большем разрешении без нужды.
- Пока канвас за пределами экрана или вкладка свёрнута, кадры не рисуются вообще.
- Геометрия перестраивается только при смене цвета, а не каждый кадр.

### Если WebGL недоступен

Старый браузер или отключённое аппаратное ускорение — не проблема: `init()`
вернёт `null`, скрипт спрячет канвас и покажет статичную иллюстрацию из `img/`.
Ни одной ошибки в консоли, страница работает дальше.

### Как поменять кухню

Вся сцена собирается в функции `buildKitchen()`. Координаты в метрах,
начало координат — на полу по центру. Чтобы добавить, скажем, холодильник,
достаточно одной строки:

```js
b.box(x, y, z, ширина, высота, глубина, цвет);
```

Цвета фасадов, столешницы и фурнитуры приходят снаружи из конструктора,
остальные заданы прямо в функции.

## Конструктор и цены

Цена считается по погонным метрам и складывается из трёх ставок:

```
цена = (материал фасадов + столешница + фурнитура) × длина кухни
```

Ставки лежат прямо в разметке, в атрибутах `data-price` — править их можно
без единой строки JavaScript:

```html
<label class="chip">
  <input type="radio" name="mat" value="oak" data-price="78000">
  <span>Массив дуба<em>78 000 ₽/м.п.</em></span>
</label>
```

Цвета фасадов задаются атрибутом `value` (он же уходит в трёхмерную сцену)
и `data-name` для подписи. Чтобы добавить новый цвет, скопируйте один
`<label class="swatch">` и поменяйте два атрибута.

Собранная конфигурация автоматически подставляется в форму заявки — менеджер
сразу видит, что именно человек выбрал, и не переспрашивает по телефону.

## Безопасность

- **Content-Security-Policy** — страница грузит только собственные файлы.
- **Никаких `onclick` и `style=""` в разметке.** Все обработчики и динамические
  цвета выставляются из JavaScript через CSSOM — такие стили под запрет CSP
  не попадают, а вот атрибут `style` в HTML был бы заблокирован. Именно поэтому
  образцы цвета хранятся в `data-sw`, а не в inline-стилях.
- **Защита от XSS** — данные выводятся только через `textContent`.
- **Ловушка для ботов** (honeypot) — скрытое поле, которое человек не видит.
- **Ограничение длины** — значения обрезаются, телефон приводится к цифрам.
- **Нет `eval` и `new Function`.**

Что донастроить на сервере (в HTML эти заголовки не работают):

```nginx
add_header Content-Security-Policy "frame-ancestors 'none'" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
```

## Как переделать под другого клиента

**Цвета сайта** — блок `:root` в начале `css/style.css`. Смена `--emerald`
перекрашивает акценты по всей странице.

**Иллюстрации проектов** — три SVG в `img/`. Их можно заменить фотографиями:
размеры подобраны под соотношение 4:3, менять разметку не нужно.

**Тексты, цены, этапы, вопросы** — прямо в `index.html`, разделы подписаны
комментариями.

## Совместимость

Chrome, Firefox, Safari, Edge и мобильные браузеры актуальных версий.
Трёхмерная сцена требует WebGL — он есть везде с 2013 года; там, где его нет,
показывается статичная картинка.

Учтена системная настройка «уменьшить движение»: отключаются анимации,
бегущая строка и перекрутка цифр. Есть стили для печати.
