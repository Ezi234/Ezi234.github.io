# КОНТУР — лендинг каркасных домов с 3D-конструктором

Вечерний тёмно-синий лендинг: сцена во всю ширину экрана, дом с тёплым светом
в окнах, поверх — стеклянная панель настроек и карточка цены. Этажность, площадь,
отделка фасада, кровля и терраса меняют трёхмерную модель и цену на лету.
Чистые HTML, CSS и JavaScript — без фреймворков, сборки и внешних библиотек.

---

## Как запустить

Из папки `WebSites` (на уровень выше):

```bash
node dev-server.js
```

Откройте `http://localhost:5173/04-houses/`.

Открывать `index.html` двойным щелчком не стоит: в протоколе `file://` браузер
блокирует загрузку CSS и JS из-за политики безопасности, и страница будет пустой.

## Трёхмерная сцена

Никаких three.js и загрузчиков моделей — весь рендер в `js/house3d.js`:

- **Геометрия строится кодом.** Кроме коробок здесь есть `tri()` и `quad()` —
  произвольные треугольники и четырёхугольники с автоматически вычисленной
  нормалью. Именно они дают двускатную кровлю, треугольные фронтоны и ели.
- **Дом пересобирается под параметры.** Площадь и этажность пересчитываются
  в габариты: ширину, глубину, высоту стен и высоту конька. У двухэтажного
  появляется второй ряд окон, у мансардного — окно во фронтоне.
- **Свет в окнах — отдельный атрибут вершины.** У каждой вершины есть `aGlow`;
  там, где он равен единице, шейдер подмешивает тёплое свечение поверх
  освещения. Так окна и фонари «горят», не будучи источниками света.
- **Вечернее освещение**: холодный свет неба сверху, тёплый закатный ключ сбоку,
  блик и синеватая дымка вдаль, чтобы читалась глубина.
- **Управление**: перетаскивание мышью и пальцем, стрелки на клавиатуре,
  медленный автоповорот в простое.

### Бережное отношение к слабым машинам

- Плотность пикселей ограничена коэффициентом 1,75.
- Пока сцена за пределами экрана или вкладка свёрнута, кадры не рисуются.
- Геометрия пересобирается только при изменении параметров. Ползунок площади
  во время перетаскивания пересчитывает лишь цену, а модель — когда его отпустили.

### Если WebGL недоступен

`init()` вернёт `null`, скрипт спрячет канвас и покажет статичную иллюстрацию
из `img/`. Ни одной ошибки в консоли.

### Как поменять дом

Вся сцена собирается в функции `buildHouse(o)`, координаты в метрах,
начало координат — центр пятна застройки. Полезные кирпичики:

```js
b.box(x, y, z, ширина, высота, глубина, цвет, свечение);
b.quad(p1, p2, p3, p4, цвет);   // произвольная плоскость
b.tri(p1, p2, p3, цвет);        // треугольник, нормаль считается сама
```

Например, гараж — это одна коробка и один скат. Отдельная функция `fir()`
рисует ель и вызывается четыре раза с разными координатами и масштабом.

## Конструктор и цены

```
цена = (ставка за этажность + надбавка за фасад + надбавка за кровлю) × площадь
       + терраса (если выбрана)
срок = 60 дней + площадь × 0,35 + надбавка за этажность + 7 дней на террасу
```

Ставки лежат в разметке, в атрибутах `data-rate` и `data-add` — править их можно
без единой строки JavaScript:

```html
<label class="chip">
  <input type="radio" name="floors" value="2" data-rate="42000">
  <span>Два этажа<em>42 000 ₽/м²</em></span>
</label>
```

Цена террасы задана константой `TERRACE_PRICE` в начале блока конструктора
в `js/main.js`.

Собранная конфигурация автоматически подставляется в форму заявки и в модальное
окно — менеджер сразу видит, что человек выбрал, и не переспрашивает.

Сроки склоняются по правилам русского языка: 1 день, 2 дня, 121 день, 150 дней.

## Что ещё работает

| Блок | Поведение |
|---|---|
| Шапка | Прилипает, прячется при движении вниз, возвращается при движении вверх |
| Полоса прогресса | Показывает, сколько страницы прочитано |
| Заголовок | Строки выезжают снизу при загрузке |
| Звёздное небо | Нарисовано градиентами, мерцает; ни одной картинки |
| Кнопки | Основные слегка тянутся к курсору, по ним пробегает блик |
| Комплектации | Карточки наклоняются вслед за курсором |
| Этапы | Линия таймлайна заполняется по прокрутке, точки загораются по очереди |
| Проекты | Фильтр по этажности и лайтбокс со стрелками, клавишами и ценой |
| Вопросы | Аккордеон: открыт один пункт, высота анимируется без скачков |
| Формы | Маска телефона, проверка полей, понятные ошибки, уведомления |
| Модальное окно | Закрывается по Esc, оверлею и крестику, удерживает фокус внутри |

и встают под ней — сцена остаётся видимой целиком.

## Безопасность

- **Content-Security-Policy** — страница грузит только собственные файлы.
- **Никаких `onclick` и `style=""` в разметке.** Цвета образцов приходят из
  `data-sw` и выставляются через CSSOM: такие стили CSP не блокирует,
  а атрибут `style` в HTML был бы заблокирован.
- **Защита от XSS** — данные выводятся только через `textContent`.
- **Ловушка для ботов** (honeypot) — скрытое поле, которое человек не видит.
- **Ограничение длины** — значения обрезаются, телефон приводится к цифрам.
- **Нет `eval` и `new Function`.**

Что донастроить на сервере (в HTML эти заголовки не работают):

```nginx
add_header Content-Security-Policy "frame-ancestors 'none'" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;
```

## Как переделать под другого клиента

**Цвета сайта** — блок `:root` в начале `css/style.css`. Смена `--amber`
перекрашивает акценты по всей странице, `--bg` задаёт общее настроение.

**Иллюстрации проектов** — три SVG в `img/`, соотношение 16:11.
Заменяются фотографиями без правки разметки.

**Тексты, цены, этапы, вопросы** — прямо в `index.html`, разделы подписаны
комментариями.

## Совместимость

Chrome, Firefox, Safari, Edge и мобильные браузеры актуальных версий.
Трёхмерная сцена требует WebGL; там, где его нет, показывается иллюстрация.

Учтена системная настройка «уменьшить движение»: отключаются анимации,
мерцание звёзд, бегущая строка и перекрутка цифр. Есть стили для печати.
