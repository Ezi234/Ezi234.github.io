Что входит в каждый сайт

  • Адаптив от 375 px: телефон, планшет, десктоп — проверено, а не «должно работать»
  • Формы с проверкой полей, понятными ошибками и маской телефона
  • Защита от спам-ботов и от XSS через пользовательский ввод
  • Content-Security-Policy: страница не грузит ничего со сторонних доменов
  • Заголовки безопасности для хостинга: сайт нельзя встроить в чужую страницу, только HTTPS, вставка HTML строкой запрещена браузером
  • Доступность: навигация с клавиатуры, ловушка фокуса в модальном окне, поддержка режима «уменьшить движение»
  • Инструкция по запуску, настройке и подключению формы к серверу
  • Исходники целиком: html + css + js, без сборки и подписок
Локальный просмотр: node dev-server.js в папке WebSites
